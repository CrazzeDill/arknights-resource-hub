# Arknights Resource Hub

A community-maintained resource hub for Arknights players, compiling the most useful guides, tools, and information in one place.

## About

This website serves as a centralized repository for Arknights resources that were previously scattered across various Discord channels, Google Docs, and personal websites. It's designed to help both new and experienced players find the information they need quickly and efficiently.

## Features

- **Base Resources**: Worker combos, layout efficiency, and productivity guides
- **Future Content**: Predicted banners, events, and skins from CN server
- **Efficiency Guides**: Farming optimization, resource management
- **Various Utilities**: Essential tools like Aceship, Krooster, and Penguin Stats
- **Video Guides**: Kukkikaze's comprehensive video content
- **Written Guides**: Detailed written resources on mechanics, operators, and events

## Development

This site is built with [Astro](https://astro.build/), a modern static site generator.
